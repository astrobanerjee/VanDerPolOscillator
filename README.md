# VanDerPolOscillator
Interactive Driven Van der Pol Oscillator Simulation | Tech Stack: JavaScript, HTML5 Canvas, CSS. Engineered a browser-based computational physics simulation to model non-linear dynamics and chaotic systems. 
Implemented a highly stable 4th-Order Runge-Kutta (RK4) numerical solver to accurately integrate the Van der Pol differential equation in real-time.
➤ Designed a responsive, dual-canvas graphical interface that simultaneously renders a driven spring-mass animation and an active phase portrait plotting velocity versus position.
➤ Integrated live UI slider controls allowing instant manipulation of the system's non-linearity, driving amplitude, and driving frequency.
